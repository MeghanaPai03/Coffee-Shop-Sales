# Coffee Shop Sales Analysis Dashboard

## Project Overview

This project analyzes retail sales data from a coffee shop chain using Microsoft Excel. The goal is to transform raw transactional data into meaningful business insights through data cleaning, analysis, visualization, and interactive dashboard creation.

The dashboard helps stakeholders monitor key performance indicators (KPIs), understand customer purchasing behavior, identify top-performing products, and evaluate store performance.

**Dataset Source:** Maven Analytics – Coffee Shop Sales Dataset

## Objective

The objective of this project is to analyze coffee shop sales data and provide actionable insights that can support business growth and operational decision-making.

## Analysis Objective

* What is the overall sales performance of the coffee shop?
* How does customer order volume vary throughout the day?
* Which products generate the highest sales revenue?
* How are orders distributed across different product sizes?
* How do sales and footfall vary across store locations?
* What is the sales contribution of each product category?
* How do orders and sales vary across weekdays?
* How does sales performance change when filtered by month and day?

* Identify top-performing products based on sales revenue.
